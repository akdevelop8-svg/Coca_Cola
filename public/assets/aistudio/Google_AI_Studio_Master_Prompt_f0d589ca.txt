## 15. Technical implementation requirements

Build this as a maintainable React + TypeScript web app suitable for Google AI Studio Build mode:
- Use React Router (or a clean equivalent) for routes.
- Use reusable page components, shared header, sidebar, mobile bottom navigation, cards, section headers, modals, tables and form controls.
- Use lucide-react icons (or one consistent icon library); do not mix random icon styles.
- Use Tailwind CSS or well-structured CSS modules with design tokens.
- Keep plan and settings data in typed configuration files, not scattered through components.
- Create a clean service/data layer with mock adapters so the later Supabase integration can replace the demo adapter without rewriting UI components.
- Do not create a Supabase schema or connect credentials in this phase.
- Do not add real payment gateways, crypto wallets, bank-transfer automation or live money movement in this phase.
- Do not store passwords, bank credentials, payment credentials or sensitive data in localStorage.
- Use environment variables only for secrets if any are later added; never expose secrets in browser code.
- Add accessible labels, keyboard-focus styles, semantic markup, loading states, empty states, error states and confirmation dialogs.
- All buttons and navigation controls must work in the prototype; avoid decorative buttons that do nothing.
- Make every amount display consistently formatted as “Br 1,500” and use the same currency formatter throughout.
- Add a README describing the project, routes, assets and how to run it.

Before any live deposits, investments, referral commissions or withdrawals are enabled, the owner must validate the underlying revenue source, payout capacity, exact programme terms, all required financial permissions/licences, and authorization for the brand use.
